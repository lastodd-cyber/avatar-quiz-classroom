# 아바타 퀴즈 교실

학생이 QR로 들어와 자기를 닮은 캐릭터를 만들고, 한 교실에서 함께 움직이며 선생님이 낸 퀴즈를 푸는 웹 교실입니다. 3·2·1 카운트다운 뒤 가장 빨리 맞힌 학생의 캐릭터가 큰 연출로 등장하고, 마지막에는 1·2·3등 시상식과 상위 5명이 함께하는 협동 게임방이 열립니다.

- 사용법(그림 포함): (준비 중)
- 한 교실 40명 정도를 기준으로 만들었습니다.

## 내 교실 서버 만들기

아래 버튼을 누르면 Render 무료 서버에 내 교실이 만들어집니다. Render 계정(구글로 가입 가능)만 있으면 되고, GitHub 계정은 없어도 됩니다.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/lastodd-cyber/avatar-quiz-classroom)

1. 버튼을 누르고 Render에 로그인합니다.
2. 이름은 그대로 두고 **Deploy Blueprint**(또는 Apply)를 누릅니다. 처음 만들 때 5~10분쯤 걸립니다.
3. 만들어진 서비스 → **Environment**에서 `TEACHER_KEY` 값을 복사해 둡니다. 교실을 만들 때 넣는 교사용 키입니다. 학생에게 알려 주지 않습니다.
4. 서비스 위쪽의 `https://….onrender.com` 주소 뒤에 `/teacher?avatar=v05`를 붙여 엽니다. 여기서 **교실 만들기**를 합니다. 이 주소로 열어야 새 캐릭터로 만들어지니 즐겨찾기해 두세요.

무료 서버는 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 1분쯤 걸려 깨어납니다. 수업 몇 분 전에 선생님 화면을 먼저 열어 두세요. 서버가 다시 켜지면 열려 있던 교실·점수·대화는 사라집니다.

## 학생 정보

- 로그인·실명·학번을 받지 않습니다. 학생은 별명으로 들어옵니다.
- 사진은 학생 휴대폰 안에서만 분석하고 서버로 보내거나 저장하지 않습니다.
- 서버에는 별명·캐릭터 설정·대화·답안이 수업 중에만 메모리에 있고, 서버가 꺼지면 사라집니다.

## 내 PC에서 실행하기 (같은 와이파이)

Node.js 24가 필요합니다.

```text
npm ci
npm run build
npm start
```

`http://localhost:3210/teacher`에서 교실을 만듭니다. 학생 휴대폰은 PC와 같은 와이파이여야 합니다.
